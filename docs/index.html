AJUDA
Como atualizo?

Baixe a versão mais recente. O Android abrirá o instalador e poderá pedir confirmação e permissão para instalar a atualização.

As minhas músicas são enviadas para um servidor?

O player foi desenhado para trabalhar com a biblioteca local do dispositivo. As estatísticas do Journey são guardadas localmente.

Como funciona o Bluetooth?

O app pesquisa dispositivos próximos e apresenta o nome encontrado. A etapa final de emparelhamento ou ligação é controlada pelo Android.
